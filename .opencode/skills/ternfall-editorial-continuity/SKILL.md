# Ternfall Editorial Continuity

1. Identify the current project and supplied canon; do not import Ternfall world rules into another project or assume stored material is approved.
2. Track who knows what, physical geography, causal choices, resources and consequences using cited evidence; mark missing information unknown.
3. Treat word counts and WPM as estimates, and keyword heuristics as incomplete warnings. Human editorial, factual and rights review remains required.
4. Never imitate competitors or silently alter published/historical creative records. Request explicit authorization for new versions or reconciliation.
