# Ternfall Release Readiness

1. List release prerequisites and owners: security, clean builds, platform coverage, data backup/restore, operational recovery, accessibility, rights and independent editorial review.
2. Verify which CI jobs actually run, which binaries/providers are maintained, and which tests are skipped. A green suite or example YAML is not certification.
3. Identify blocking and conditional gaps with reproducible evidence, mitigations and rollback plans.
4. Never publish, schedule, change privacy, tag, merge or grant/widen spending solely because a skill recommends it; obtain explicit human authorization.
