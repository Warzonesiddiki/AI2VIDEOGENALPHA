# Ternfall Product Truth

1. Trace each success, ready, verified, approval, cost and health label to actual persisted evidence and its scope/time.
2. Clearly label drafts, stale/unknown provenance, historical records and last-checked evidence. Never infer rights, editorial approval, real provider status or publication permission from technical QC.
3. Retire unsafe simulated commands and executable generators instead of returning successful fabricated artifacts.
4. Verify UI, API, CLI, docs and seed data consistently; expose actionable failures rather than silently displaying defaults.
