# Command: /episode-plan

1. Confirm the selected project and obtain only the necessary project-scoped context through the typed CLI with the operator's authorization.
2. Treat continuity and the stored bible as unverified source material; do not infer that either is approved or complete.
3. Propose a distinct objective, dramatic question, human conflict and consequence in the selected project's own story world.
4. If the operator requests a draft, use the documented scoped creation command with an idempotency key. Never create or overwrite production data implicitly.
5. Episode checks are advisory and do not establish readiness, canon compliance or approval.
